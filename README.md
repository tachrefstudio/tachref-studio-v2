## 🎨 Visual Identity & Key Features

1. **Aesthetic Framework**:
   - **Background**: Deep black (`#0B0B0C`).
   - **Grid System**: Viewport-wide thin vertical grid columns (`rgba(255, 255, 255, 0.04)`).
   - **Ambient Lighting**: Subtle orange/amber glow flares (`rgba(255, 107, 43, 0.14)`) combined with Conatus-inspired glowing button top rims (`box-shadow: 0 -6px 20px -3px rgba(255, 107, 43, 0.4)`).
   - **Typography**: Dual display pairing featuring `Syne` (editorial headlines) and `Space Grotesk` (technological body), complemented by `JetBrains Mono` for micro-telemetry.

2. **Hero Section**:
   - Left: Brand pill, headline *"CREATIVITY FIRST. TECHNOLOGY DRIVEN. BUILT TO EXPLORE."*, supporting narrative, and dual CTAs (*Start a Conversation* & *Explore Our Work*).
   - Right: 3D iridescent holographic sculpture with animated orbital rings and interactive department tags.

3. **Seven Studio Departments**:
   - `01 — WEB DEVELOPMENT`: Websites, web applications, frontend and backend development.
   - `02 — GRAPHIC DESIGN`: Digital artwork, posters, graphics and visual communication.
   - `03 — BRANDING & LOGO DESIGN`: Brand identity, logo systems and visual storytelling.
   - `04 — GAME DEVELOPMENT`: Browser games, interactive experiences and game concepts.
   - `05 — UI/UX DESIGN`: Digital interfaces, product design and user experiences.
   - `06 — ROBOTICS`: Robotics, electronics, automation and engineering experiments.
   - `07 — CREATIVE TECHNOLOGY`: Creative coding, emerging technologies and experimental innovation.

4. **Interactive Highlights**:
   - Live **Interactive Particle/Quantum Field Canvas** in the Lab tracking cursor gravity.
   - Instant multi-category **filtering** on projects and department works.
   - **Quick-View Modal Dialog** for inspecting architecture and concept specifications.
   - Smooth custom trailing cursor with magnetic reaction states.
   - Live UTC studio operational clock.

## 🚀 GitHub Pages Deployment

To deploy this redesign to your live site (`https://tachrefstudio.github.io/tachref-studio/`):

1. Commit all files in this directory to your repository's `main` (or `gh-pages`) branch:
   ```bash
   git add .
   git commit -m "Redesign: TACHREF STUDIO flagship editorial website"
   git push origin main
   ```
2. In your GitHub repository settings, navigate to **Pages** and confirm the source is set to `/ (root)`.
3. Your new website will be live immediately!
